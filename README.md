# Signal Sprint

A no-build, static practice quiz for mobile communications, based on the topics in the CENG645 ungraded self-assessment. The 59 prompts are rewritten for practice and include answer explanations and study tips.

## Run locally

Open `index.html` in a browser. The quiz uses plain HTML, CSS, and JavaScript and does not require a server, account, or build step.

## Publish

Upload these files to any static web host, such as GitHub Pages, Netlify, or Cloudflare Pages. No environment variables or backend are required.

The page imports Google Fonts when online; the system font fallback keeps it usable offline.
